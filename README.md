# 凯利仓位实验台

中文、响应式的静态网页，用于研究胜率、盈亏幅度、买入仓位和回撤的关系。打开 `index.html` 即可使用；无需服务器、构建步骤或第三方 JavaScript 包。页面不连接行情，也不生成交易建议或收益预测。

## 资金与仓位单位

输入的平均盈利和计划亏损都是**持仓金额的涨跌幅**。买入仓位 `a` 是买入金额占账户资金的比例，范围 0%–100%；交易后的账户资金按 `W_next = W × (1 + a × r)` 更新，其中 `r` 是该笔持仓扣除成本后的实际涨跌幅。满仓遇到净跌 10% 时，账户资金约跌 10%，不会因为一次普通止损而归零。

页面可切换经典两点、分布凯利和稳健分布凯利。经典两点只用估计胜率与平均净盈亏定仓；分布凯利把盈亏波动、止损收紧、滑点、成本及设定的极端事件离散成多个结果点；稳健方法再把用于定仓的胜率降低设定的百分点。三者的模拟路径都包含极端事件，区别只在定仓信息与保守程度。普通策略还受用户的**计划账户风险上限**约束；100% 满仓是独立压力对照，不受该上限约束。

## 凯利框架与交易适配

核心目标是选择买入金额占比 `a`，最大化给定收益分布下的 `E[log(1 + aR)]`，其中 `R` 是扣除执行成本后的标的涨跌幅。两点模型有盈利 `+G`、亏损 `-L` 两种结果，胜率为 `p`，无约束解为 `a* = max(0, (pG-(1-p)L)/(GL))`。当盈亏幅度只有两个固定值且概率已知时，它是解析解；超过 100% 意味着理论解需要杠杆，本网页仍限制无杠杆仓位。分布模型对每个可能结果 `r_i` 赋概率 `q_i`，数值求解 `sum(q_i log(1+a r_i))` 在 0%–100% 内的峰值。收益分布不确定时，可以缩小仓位、对概率设保守范围，或优化最不利可信情景；这属于稳健凯利思想，而不是原公式自动具有的保护。

凯利框架也用于重复投注、投资组合权重、资产配置、赔率定价与资本分配。多资产时，需要联合收益分布及相关性，不能把单资产公式分别套用后简单相加。本项目的“组合实验”在市场模式下联合配置打板、波段、趋势与现金，以共享市场状态和尾部冲击表示部分共同风险；其余单策略图表仍是一笔一个标的的实验。

交易适配至少涉及：净收益和费用、止损失效与跳空、胜率估计误差、行情状态的持续与误判、流动性和冲击成本、杠杆/保证金规则、可承受的回撤及资金容量。当前界面的尾部事件是**用户指定的压力假设**：默认每笔 2% 概率发生标的净跌 60%，覆盖该笔普通胜负；它不是从历史数据估计出的黑天鹅频率。稳健方法默认把用于定仓的胜率折减 5 个百分点，但普通交易结果仍按原设定胜率抽样。若真实损失比设定更严重，或尾部风险未被列入分布，凯利解仍可能严重偏大，甚至归零；凯利公式不能自动解决未知黑天鹅。

## 三种模式与执行假设

- 基础模式：设置胜率、平均盈利百分比和计划亏损百分比；毛盈亏比会同步计算，也可以反向编辑。
- 估计误差模式：使用 Beta(1,1) 先验。每条重复模拟路径从后验抽取一次可能的真实胜率，定仓仍只使用历史数据的后验均值。
- 市场变化模式：顺风、普通、逆风状态各有胜率和平均盈亏幅度；隐藏状态按持续概率留在当前状态，否则等概率切换到其他状态。首笔隐藏状态从该转换矩阵的平稳分布抽取。交易前出现一个可误判的状态信号，信号准确率由用户设置；模型按转换矩阵、当笔信号和过去交易结果更新三个状态的概率。仓位根据这些交易前概率混合收益分布求解，不读取隐藏真实状态。单策略按 1 个百分点、组合按 5 个百分点的概率网格缓存求解结果，精度受此影响。
- 基础模式每笔按固定胜率独立抽样；估计误差模式同一路径中的交易共享一次抽到的真实胜率，因此条件于该胜率后独立；市场变化模式按状态持续概率产生连续的顺风/逆风阶段，交易之间有相关性。改变信号准确率不会重新抽取隐藏状态或交易结果，改变仓位约束也不会重新抽取交易结果。
- 每笔普通盈利和亏损幅度在设定范围内均匀波动。设定比例的亏损单按“收紧后亏损幅度”执行，其余按原计划亏损执行；亏损再叠加 0 到滑点上限之间的随机额外损失，所有普通交易都扣除往返成本。极端事件以设定概率覆盖该笔普通结果，用户输入的是事件发生后的标的**净跌幅**。这是条件化的执行模型，并不生成盘中价格路径，不能保证实际止损成交。

七种仓位策略使用同一批持仓净涨跌幅比较。资金路径、回撤和最终资金分布来自重复模拟；经验增长图同时显示同批结果的平均对数增长，以及只使用胜率和平均盈亏的理想两点凯利曲线，并标记当前所选方法的模型解。长期平均对数增长为正只说明典型复合趋势有利，不保证单条路径逐笔上升；连续亏损、估计误差和状态持续性都可能造成深回撤。最终资金概率图保留归零路径，并将所有策略放到同一资金坐标轴比较；柱状图是对数资金区间的经验频率，平滑线不是正态拟合，紫色虚线仅是对正资金样本的对数正态参照。

市场模式下的组合实验提供可编辑的波段、趋势胜率、盈亏幅度、共同冲击损失、单项上限、总买入仓位上限及固定配置。打板参数沿用市场状态模型。优化目标为三个策略与现金的联合预期对数增长，枚举条件于每个市场状态的普通输赢组合，并加入共同尾部事件；采用无杠杆网格搜索，因此权重是近似数值解。审慎配置比较当前状态概率与顺风概率下移的情景，选择两者中较低的预期对数增长；用户设定偏移幅度。固定、信号概率、审慎配置和“真实状态已知”参照使用同一批各策略收益，最后一种只用于衡量信息价值，无法在实际交易前获得。组合的普通策略收益条件于市场状态独立，共同冲击则同时造成损失；未建模交易间持仓、未成交、换仓滑点和相关策略的日常共同波动。

默认模拟一年约 240 个交易日、每天一笔，共 240 笔，重复 500 次，初始资金 10,000 元。随机种子默认 2047：相同种子和参数产生相同路径，换种子只会改变抽样结果，不改变输入胜率或期望。默认基础情景为 42% 胜率、盈利 10%、计划亏损 7%；顺风/普通/逆风状态的胜率分别为 60%/42%/32%，盈利幅度为 10%/8%/6%，亏损幅度为 5.5%/6.5%/8%，持续概率为 65%/78%/90%。这些是可编辑的情景假设，用来体现短强长弱，不是 A 股统计估计或收益预测。默认往返成本为持仓金额的 0.1%，超凯利倍数为 1.25。交易次数上限为 20,000，重复模拟次数上限为 5,000，单次最多处理 500 万笔结果；极端金额在图表中截断显示，回撤仍按对数资金计算。

## 限制

模型未模拟盘口深度、冲击成本、涨跌停无法成交、停牌、T+1 卖出限制、实际交易机会频率、资金容量或优势随资金规模衰减。组合实验也不读取历史成交记录，信号准确率、策略相关性和不利情景幅度都是人工设定。对超短线打板而言，成交与退出限制尤其重要。请把输入视为可检验的假设，结合自己的历史成交数据校准，不应把模拟最终资金解读为未来收益预测。
