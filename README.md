# 凯利仓位实验台

中文、响应式的静态网页，用于研究胜率、盈亏幅度、买入仓位和回撤的关系。打开 `index.html` 即可使用；无需服务器、构建步骤或第三方 JavaScript 包。页面不连接行情，也不生成交易建议或收益预测。

## 资金与仓位单位

输入的平均盈利和计划亏损都是**持仓金额的涨跌幅**。买入仓位 `a` 是买入金额占账户资金的比例，范围 0%–100%；交易后的账户资金按 `W_next = W × (1 + a × r)` 更新，其中 `r` 是该笔持仓扣除成本后的实际涨跌幅。满仓遇到净跌 10% 时，账户资金约跌 10%，不会因为一次普通止损而归零。

页面可切换两点凯利和多点/分布凯利。两点凯利根据估计胜率、净盈利幅度和平均净亏损幅度求无约束买入比例；分布凯利则把盈亏幅度波动、止损收紧、滑点和成本离散成多个结果点，数值求解 0–100% 无杠杆范围内的期望对数增长峰值。界面同时显示两点参照对应的账户风险比例 `a × 平均净亏损幅度`。两种方法都是模型参照，不是交易建议。普通策略再按用户设定的**计划账户风险上限**约束；100% 满仓用于比较，不受普通风险上限约束。

## 三种模式与执行假设

- 基础模式：设置胜率、平均盈利百分比和计划亏损百分比；毛盈亏比会同步计算，也可以反向编辑。
- 估计误差模式：使用 Beta(1,1) 先验。每条重复模拟路径从后验抽取一次可能的真实胜率，定仓仍只使用历史数据的后验均值。
- 市场变化模式：顺风、普通、逆风状态各有胜率和平均盈亏幅度；从普通状态开始，每笔后按持续概率留在当前状态，否则等概率切换到其他状态。定仓只使用当前状态参数。
- 基础模式每笔按固定胜率独立抽样；估计误差模式同一路径中的交易共享一次抽到的真实胜率，因此条件于该胜率后独立；市场变化模式按状态持续概率产生连续的顺风/逆风阶段，交易之间有相关性。
- 每笔盈利和亏损幅度在设定范围内均匀波动。设定比例的亏损单按“收紧后亏损幅度”执行，其余按原计划亏损执行；亏损再叠加 0 到滑点上限之间的随机额外损失，所有交易都扣除往返成本。这是条件化的执行模型，并不生成盘中价格路径，不能保证实际止损成交。

七种仓位策略使用同一批持仓净涨跌幅比较。资金路径、回撤和最终资金分布来自重复模拟；经验增长图同时显示同批结果的平均对数增长，以及只使用胜率和平均盈亏的理想两点凯利曲线，并标记当前分布凯利解。长期平均对数增长为正只说明典型复合趋势有利，不保证单条路径逐笔上升；连续亏损、估计误差和状态持续性都可能造成深回撤。最终资金概率图保留归零路径，并将所有策略放到同一资金坐标轴比较；柱状图是对数资金区间的经验频率，平滑线不是正态拟合，紫色虚线仅是对正资金样本的对数正态参照。

默认模拟一年约 240 个交易日、每天一笔，共 240 笔，重复 500 次，初始资金 10,000 元。随机种子默认 2047：相同种子和参数产生相同路径，换种子只会改变抽样结果，不改变输入胜率或期望。默认基础情景为 42% 胜率、盈利 10%、计划亏损 7%；顺风/普通/逆风状态的胜率分别为 60%/42%/32%，盈利幅度为 10%/8%/6%，亏损幅度为 5.5%/6.5%/8%，持续概率为 65%/78%/90%。这些是可编辑的情景假设，用来体现短强长弱，不是 A 股统计估计或收益预测。默认往返成本为持仓金额的 0.1%，超凯利倍数为 1.25。交易次数上限为 20,000，重复模拟次数上限为 5,000，单次最多处理 500 万笔结果；极端金额在图表中截断显示，回撤仍按对数资金计算。

## 限制

模型未模拟盘口深度、冲击成本、涨跌停无法成交、停牌、T+1 卖出限制、实际交易机会频率、资金容量或优势随资金规模衰减。对超短线打板而言，这些因素尤其重要。请把输入视为可检验的假设，结合自己的历史成交数据校准，不应把模拟最终资金解读为未来收益预测。

## 验证与发布

在有 Node.js 的环境中运行 `node --test sim.test.js`。发布到 GitHub Pages 时可把本目录作为静态站点内容；正式公开前请为仓库选择许可证。页面不保存输入，也不向外部服务发送数据。
